# CreditWise-Loan-System
AIML - based loan approval prediction system using Python and Machine Learning
# CreditWise Loan System

## 1. Project Overview

CreditWise Loan System is an AIML-based machine learning project that
predicts whether a loan application is likely to be approved or rejected
based on applicant information.

The project applies data preprocessing, exploratory data analysis (EDA),
feature engineering, and machine learning techniques to build and evaluate
loan approval prediction models.

---

## 2. Objective

The main objective of the CreditWise Loan System is to:

- Predict loan approval status.
- Analyze important factors affecting loan approval.
- Apply different machine learning algorithms.
- Compare the performance of multiple classification models.
- Select the best-performing model based on evaluation metrics.

---

## 3. Dataset

The project uses a loan application dataset containing information about
applicants and their loan applications.

The dataset includes features such as:

- Gender
- Married
- Dependents
- Education
- Self Employed
- Applicant Income
- Coapplicant Income
- Loan Amount
- Loan Amount Term
- Credit History
- Property Area

The target variable is:

- Loan Approval Status

---

## 7. Machine Learning Models

Three classification algorithms are implemented and compared:

### 1. Logistic Regression

Logistic Regression is used as a classification algorithm to predict
whether the loan application will be approved or rejected.

### 2. K-Nearest Neighbors (KNN)

KNN classifies a loan application based on the similarity between the
application and its nearest data points.

### 3. Naive Bayes

Naive Bayes is a probabilistic classification algorithm used to predict
the loan approval status based on the input features.

---

## 8. Model Evaluation

The models are evaluated using the following metrics:

- Accuracy
- Precision
- Recall
- Confusion Matrix

These metrics are used to compare the performance of Logistic Regression,
KNN, and Naive Bayes.
